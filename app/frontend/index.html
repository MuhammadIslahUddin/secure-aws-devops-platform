📋 Project Overview

This project implements a defense-in-depth, zero-trust cloud architecture on Amazon Web Services, designed and deployed entirely through Infrastructure-as-Code (IaC). It demonstrates how enterprise-grade systems are built — with security, automation, and reliability as the core foundation.

Key Design Principles

  • No public exposure: Application and backend servers reside in private subnets with zero public IP addresses — unreachable directly from the internet.
  • Least privilege: Security groups enforce strict inbound/outbound rules — only explicitly allowed traffic flows.
  • Centralized control: All outbound traffic from private tiers routes through a dedicated forward proxy for logging, filtering, and caching.
  • Automation-first: Every resource is version-controlled and deployable in minutes — no manual console setup.
  • Environment separation: Distinct dev/prod configurations enable safe iteration before production changes.

🏗️ Architecture Breakdown

1. Public Edge Layer

  • Application Load Balancer (ALB): Single public entry point — accepts HTTP traffic from anywhere and distributes it across frontend instances.
  • Future-ready for HTTPS/TLS (AWS Certificate Manager integration) and Web Application Firewall (WAF).

2. Outbound Gateway Layer

  • Squid Forward Proxy: Acts as the sole internet gateway for private-tier workloads. Enforces access policies, logs all external requests, and reduces bandwidth via caching.
  • Port 8888 — accessible only from private application subnets.

3. Private Application Tier

  • Frontend (Nginx): Serves the user interface. Receives traffic only from the ALB — never directly from the internet.
  • Backend API (Python/Flask): Provides data services. Accepts connections only from the frontend tier.
  • ⚠ Neither server has a public IP — administration requires VPN or bastion access.

4. Administration & Security Layer

  • OpenVPN Server: Provides secure, encrypted tunnel for administrative access — SSH is never exposed publicly.
  • Restricted SSH: Only permitted from your trusted IP or VPN address.
